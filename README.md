# Ascendia CRM for Phil Labor
**Full-Stack Node.js + Express + Supabase**

This is the complete, production-ready version of the Ascendia CRM dashboard — now migrated to **Supabase** (PostgreSQL).

## Environment Variables

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
JWT_SECRET=ascendia-phil-labor-super-secret-2026
```

## Quick Start

```bash
npm install
npm start
```

## Features
- Beautiful modern dashboard
- Staff, Tasks, Tickets, Clients from Supabase
- JWT Authentication
- Deploy new staff
- AI Assistant (Annie)
